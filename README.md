# Stewy's Cards & Collectables

Static website for StewysCards.com.

## Easy editing
- `content.js` contains the main site text, email, social links, and event details.
- `about.html` contains the About Me page text.
- Replace images in `assets/` if you want different artwork.

## Pages
- Home
- About Me
- Shop (placeholder for future online sales)
- Events (single current event)

## Publishing
This is a plain HTML/CSS/JS site and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or another static host.
